# EduPro — منصة تعليم أونلاين لكل المواد (Backend + API)

Backend كامل بـ **Django 5/6 + Django REST Framework** مصمم API-first لتطبيق **Flutter** (Android / iOS / Web)،
ومعاه موقع عام سريع مبني بـ Django Templates عشان **SEO** (المواد، المدرسين، الكورسات، الأسئلة والأجوبة، المدونة).

## الفيتشرز

| الوحدة | اللي فيها |
|---|---|
| الحسابات | 4 أدوار (أدمن، مشرف، مدرس، طالب) — دخول بالموبايل أو الإيميل — JWT — OTP لتأكيد الموبايل ونسيت كلمة السر — حذف الحساب (مطلوب من المتاجر) |
| المدرسين | طلب انضمام + رفع مستندات → مراجعة واعتماد الإدارة — تعيين مشرف لكل مدرس — مواعيد متاحة أسبوعياً — تقييمات |
| المواد | مناهج → مراحل → صفوف → مواد (لكل المواد: دراسي، لغات، قرآن، مهارات) |
| الحصص اللايف | باقات — اشتراكات — جدول أسبوعي ثابت — توليد الحصص تلقائياً — **غرفة حصة جوه الموقع** (صالة انتظار بعداد واختبار كاميرا ومايك، فيديو مدمج، ساعة الحصة، الطرف التاني دخل ولا لأ لحظياً، ملاحظات المدرس بتتنقل للتقرير) — Jitsi بـ JWT أو 8x8 JaaS (المدرس moderator) — تقييم الطالب للحصة — دخول/إنهاء/إلغاء/غياب — تقرير بعد كل حصة يوصل للطالب — تقييم جودة من المشرف — طلبات تغيير ميعاد — حصة تجريبية مجانية — منع تعارض مواعيد المدرس |
| الكورسات المسجلة | وحدات ودروس (فيديو/PDF/نص) — **المدرس يرفع فيديو مباشر أو يحط رابط يوتيوب/فيميو** — كل درس: مجاني للكل / للمسجلين / بعد الدفع (والإدارة تتحكم في الكل) — الكورس ممكن يتفتح ببلاش لطلاب الحصص اللايف — **الفيديو المرفوع محمي** (برا media، رابط موقّع مؤقت، علامة مائية باسم الطالب) — مشغل بيكمّل من مكان ما وقفت — ملاحظات على الفيديو بالدقيقة — شهادة إتمام بصفحة تحقق — معاينة مجانية في صفحة الكورس العامة (VideoObject) — مراجعة ونشر من الإدارة |
| الواجبات والامتحانات | 6 أنواع أسئلة — تصحيح تلقائي + يدوي للمقالي/الملفات — وقت محدد — عدد محاولات — إرسال لطلاب معينين بميعاد تسليم — النتيجة توصل للطالب فوراً |
| الشات | شات لحظي (WebSocket) مدرس↔طالب↔الدعم — **فلتر منع التواصل خارج المنصة** (أرقام حتى لو بالعربي أو بالحروف، لينكات، إيميلات، واتساب/تليجرام...) — الإدارة والمشرف يراقبوا كل المحادثات ويشوفوا النص الأصلي |
| الإشعارات | داخل التطبيق + لحظي بالـ WebSocket + Push بـ Firebase (FCM HTTP v1) — تذكير قبل الحصة |
| الدفع | Paymob Unified Checkout (فيزا، محافظ، فوري) — Webhook بتحقق HMAC — أكواد خصم — دفع يدوي يأكده الأدمن |
| لوحات التحكم | Dashboard لكل دور — تقرير ساعات المدرسين الشهري للمحاسبة — إيرادات بالشهر |
| تطبيق الويب | صفحة دخول واحدة على `/login/` وكل دور يروح للوحته: طالب، مدرس، مشرف، أدمن — مبني على نفس الـ API |
| الأسئلة والأجوبة | الطالب يسأل في أي مادة (بصورة) والمدرسين المتخصصين يتبلغوا ويجاوبوا — تصويت — أفضل إجابة — تبويبات (الأحدث، بدون إجابة، الأكثر تفاعلاً، أسئلتي، أسئلة موادي) — أي رقم/لينك يدخل مراجعة الإدارة — صفحة عامة لكل سؤال بـ QAPage schema |
| المدونة | تصنيفات ووسوم — المدرس يكتب بمحرر فيه فحص سيو لحظي ومعاينة جوجل — مراجعة ونشر من الإدارة — فهرس محتوى تلقائي ووقت قراءة وأسئلة شائعة لكل مقال — مقالات ذات صلة — RSS |
| SEO | صفحات Server-side سريعة + Schema.org (QAPage, BlogPosting, FAQPage, Person, Course, Breadcrumb, WebSite SearchAction) + sitemap index مقسّم + robots.txt + canonical + Open Graph + noindex تلقائي للصفحات الضعيفة (سؤال بدون إجابة، فلاتر، بحث) + App Links / Universal Links |

## التشغيل محلياً

```bash
python -m pip install Django djangorestframework djangorestframework-simplejwt drf-spectacular django-filter django-cors-headers channels daphne Pillow PyJWT requests
python manage.py migrate
python manage.py seed_demo --reset   # بيانات تجريبية كتير (بيمسح القديم)
python manage.py runserver
```

بعدها افتح **http://localhost:8000/login/** — صفحة دخول واحدة، وكل مستخدم بيروح للوحة بتاعته على طول.
على يمين صفحة الدخول فيه أزرار للحسابات التجريبية: دوسة واحدة تدخلك.

**كل الحسابات كلمة سرها `admin12345`** والدخول بالاسم:

| الدور | اسم الدخول |
|---|---|
| أدمن | `admin` |
| مشرف | `supervisor` · `supervisor2` |
| مدرسين | `teacher1` … `teacher12` |
| مدرسين قيد المراجعة | `pending1` · `pending2` |
| طلاب | `student1` … `student30` |

حسابات مفيدة للتجربة:
- `student1`: عنده 3 اشتراكات نشطة، وحصة تقدر تدخلها **دلوقتي**، وواجبات مستنياه، وشات مع مدرسه.
- `teacher1`: عنده حصة خلصت ومحتاجة تقرير، وتسليم محتاج تصحيح.
- `student26`: لسه جديد — جرّب بيه اشتراك جديد ودفع.
- `admin`: فيه مقال مستني مراجعة، وسؤال وإجابة فيهم أرقام مستنيين مراجعة في «مراجعة الأسئلة»، ومدرسين مستنيين اعتماد، واشتراكات محتاجة تعيين، وطلبات حصص تجريبية، ومخالفات شات.

**الدفع في بيئة التجربة:** طالما مفيش مفاتيح Paymob، الدفع بيفتح صفحة محاكاة محلية فيها زرار «ادفع (نجاح)» و «محاكاة فشل» — نفس التدفق الحقيقي بالظبط.

**الحصص اللايف:** «ادخل الحصة» بيفتح غرفة الحصة جوه الموقع على `/app/#/room/<id>`. في التجربة بنستخدم `meet.jit.si` العام، والغرفة المدمجة فيه بتقفل بعد 5 دقايق — في الإنتاج فعّل JaaS (تحت).

**الكورسات:** `teacher1` عنده كورس فيه دروس يوتيوب ودرس فيديو مرفوع مباشرة وملفات PDF. الطالب `student1` و`student3` الكورس ده مفتوح لهم ضمن اشتراك الحصص. أي طالب تاني هيلاقي أول درس مجاني وتاني درس للمسجلين والباقي مقفول.

روابط مهمة:
- تطبيق الويب: `/login/` و `/app/`
- توثيق الـ API التفاعلي: `/api/docs/` (Swagger) و `/api/redoc/`
- لوحة Django: `/admin/` (بـ `admin` / `admin12345`)

## الإنتاج على سيرفر خاص (Docker)

```bash
cp .env.example .env    # املأ القيم الحقيقية
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
```

الخدمات: PostgreSQL + Redis (للـ WebSocket والكاش) + web (Daphne) + cron (تذكيرات وصيانة كل 5 دقايق).
حط Nginx قدامهم (مثال في `nginx.conf.example`).

### قبل الإطلاق
1. **الحصص اللايف**: `meet.jit.si` العام بيقطع الاجتماعات المدمجة بعد 5 دقائق. أسهل حل: **8x8 JaaS** — اعمل حساب على jaas.8x8.vc، ولّد API key وارفع الـ public key، وحط `JITSI_JAAS_APP_ID` و`JITSI_JAAS_KID` و`JITSI_JAAS_PRIVATE_KEY_FILE` (مسار الـ private key). أو نزّل Jitsi على سيرفر خاص بـ JWT (`JITSI_DOMAIN` و`JITSI_APP_ID` و`JITSI_APP_SECRET`).
1. **الفيديوهات المرفوعة**: بتتحفظ في `PRIVATE_MEDIA_ROOT` (افتراضي `private_media/`) — اعمل لها backup. في الإنتاج فعّل `PROTECTED_MEDIA_ACCEL=true` عشان Nginx يبعت الفيديو بنفسه (المثال في `nginx.conf.example`)، وظبّط `client_max_body_size` على حجم أكبر فيديو (`VIDEO_MAX_UPLOAD_MB`). لو عايز المدرسين ما يفتحوش دروس مجاناً من غير الإدارة: `TEACHER_CAN_SET_FREE_LESSONS=false`.
2. **Paymob**: حط المفاتيح، وفي لوحة Paymob خلي Transaction processed callback = `https://DOMAIN/api/v1/payments/paymob/webhook/`.
3. **Firebase**: ملف Service Account في `secrets/firebase.json` + `FCM_PROJECT_ID`.
4. **SMS**: اربط مزوّد الـ SMS في `apps/accounts/utils.py → send_sms`.
5. `DEBUG=False` و `SECRET_KEY` قوي و `ALLOWED_HOSTS` صح.
